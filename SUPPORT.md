# Support

OverCustomise is an open-source project. Maintainer support is provided on a best-effort basis and no response-time guarantee is offered.

## Where to ask

- **Confirmed, reproducible bug:** use the [bug report form](https://github.com/MerlinStacks/personaliseit/issues/new?template=bug_report.yml).
- **Focused product proposal:** use the [feature request form](https://github.com/MerlinStacks/personaliseit/issues/new?template=feature_request.yml).
- **Security concern:** follow [SECURITY.md](SECURITY.md), never a public issue.

Before posting, search existing issues, test with the current default branch when safe, and gather the WordPress, WooCommerce, PHP, browser, and OverCustomise versions involved.

## What maintainers can help with

- Reproducible defects in OverCustomise
- Clarification of documented setup and development workflows
- Focused enhancement proposals
- Reviewing community pull requests

## What is outside project support

- General WordPress, WooCommerce, PHP, web-server, or hosting administration
- Custom store design or bespoke production-file setup
- Third-party themes, plugins, APIs, print hardware, and provider accounts
- Recovery of deleted data or files
- Legal, privacy, compliance, or production-certification advice

Never attach customer artwork, order details, API keys, webhook secrets, logs containing personal information, or other sensitive data to a public issue. Replace those values with safe examples.
