# Code of Conduct

## Our standard

We want OverCustomise to be a welcoming, constructive project. Participants are expected to:

- be respectful and considerate;
- discuss ideas and code rather than attacking people;
- welcome questions and different levels of experience;
- give specific, actionable feedback;
- acknowledge mistakes and accept reasonable correction; and
- protect private, personal, and security-sensitive information.

Unacceptable behavior includes harassment, discrimination, threats, sexualized conduct, deliberate intimidation, trolling, sustained disruption, publishing private information, or any behavior that would be inappropriate in a professional setting.

## Scope

This code applies in repository issues, pull requests, reviews, discussions, and other project spaces. It also applies when someone officially represents the project in public.

## Enforcement

Report conduct concerns privately to a repository maintainer using the contact information on their GitHub profile. Do not create a public issue that identifies affected people or includes private details.

Maintainers may edit or remove contributions and may warn, temporarily restrict, or permanently ban participants whose behavior is inconsistent with this code. Reports will be reviewed as promptly and impartially as practical, with privacy respected to the extent possible.

Maintainers who are the subject of a report must not take part in deciding its outcome.
